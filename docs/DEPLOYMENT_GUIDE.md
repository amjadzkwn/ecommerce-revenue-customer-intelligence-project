# Recruiter demo deployment

## GitHub Pages

The dashboard is static, so it can be hosted free without a Python server.

1. Create a GitHub repository and upload the project.
2. Move the contents of `app` to `docs` if your Pages configuration requires `/docs`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and choose the dashboard folder.
5. Add the published URL to the repository description, resume, LinkedIn Featured section, and portfolio project card.

## Portfolio integration

Preferred options:

- Open the live dashboard in a new tab with a clear **Try Live Dashboard** button.
- Embed the dashboard with an iframe on desktop and use an external link on mobile.
- Add a static preview image as a fallback for slow connections.

## Recruiter experience checklist

- Dashboard loads without login.
- Main KPIs are visible within five seconds.
- Filters have clear labels and a Reset button.
- The project page links to the GitHub repository and data source.
- Metric definitions disclose that realized GMV is not net revenue or profit.
- README starts with outcomes, not setup instructions.
